# 중앙 센터 — 비밀번호 보호 페이지 버전

## 구성
- `index.html`: 공개 홈페이지. 계정 로그인 없이 공개 페이지 이용 가능
- `api/unlock.js`: 입력한 공용 비밀번호를 서버에서 검증하고 HttpOnly 세션 쿠키 발급
- `api/private-page.js`: 유효한 세션 쿠키가 있을 때만 관계자 전용 문서 HTML 반환
- `vercel.json`: Vercel 배포 설정

## 1. Vercel 환경 변수 설정
Vercel 프로젝트 → Settings → Environment Variables에 아래 두 값을 등록하세요.

- `PAGE_PASSWORD`: 관계자에게 공유할 열람 비밀번호
- `PAGE_SESSION_SECRET`: 세션 서명용 무작위 비밀값 (32자 이상 권장)

`PAGE_SESSION_SECRET` 예시 생성:
```bash
openssl rand -hex 32
```
환경 변수를 등록하거나 변경한 뒤에는 반드시 재배포하세요.

## 2. 배포
프로젝트 폴더 전체를 GitHub에 올린 뒤 Vercel에서 Import → Deploy 합니다.
Framework Preset은 Other로 두면 됩니다.

## 3. 동작 방식
1. 누구나 공개 홈페이지에 접속합니다.
2. 상단의 관계자 전용 자료실을 누릅니다.
3. 공용 열람 비밀번호를 입력합니다.
4. 서버가 비밀번호를 검증하고 HttpOnly 쿠키를 발급합니다.
5. 보호된 문서는 유효한 쿠키가 있을 때만 API를 통해 전달됩니다.

비밀번호 자체는 HTML/JavaScript에 저장되지 않습니다. 개인별 계정, 회원가입, 이메일 로그인은 사용하지 않습니다.

## 4. 비밀번호 변경 및 주의
- 비밀번호 변경은 Vercel의 `PAGE_PASSWORD` 환경 변수만 수정하고 재배포하면 됩니다.
- 이 방식은 모든 관계자가 하나의 공용 비밀번호를 사용하는 구조입니다. 누가 열람했는지 개인별로 구분하지는 않습니다.
- 실제 민감한 개인정보·건강정보를 보관하는 시스템으로 사용하지 마세요. 이 프로젝트의 내부 페이지는 세계관 연출용 예시 문서입니다.
- 비밀번호를 여러 사람과 공유하면 공유한 사람 모두 접근할 수 있습니다.
